# Orfeu

Orfeu gives you one music genre and one place to listen to every day.

**Live site:** [jerryshi042003.github.io/orfeu](https://jerryshi042003.github.io/orfeu/)

## What it does

- **Genre of the day** picks one of 511 genres from Every Noise at Once. It links to that genre's "The Pulse of …" playlist on Spotify and shows a short introduction from the matching Wikipedia article.
- **Place of the day** picks one of about 700 cities and countries. It links to that place's "The Sound of …" playlist and marks the place on a world map.
- The arrows next to the date step back through earlier days, and each day has its own link (`?date=2026-10-18`).

Everyone sees the same pick on the same calendar day. There are no accounts, cookies, analytics or third-party requests. The page only links out to Spotify and Wikipedia.

## How it works

The site is plain HTML, CSS and JavaScript served by GitHub Pages from the `main` branch. Nothing is built at deploy time.

```
index.html              Genre of the day
locations/index.html    Place of the day
assets/css/orfeu.css    Styles for both pages
assets/js/orfeu.js      Picks the day's genre or place and renders it
assets/data/            genres.json and locations.json, generated by the pipeline
assets/map/world.svg    World map, generated by the pipeline
assets/fonts/           Instrument Serif (SIL Open Font License, see OFL.txt)
assets/favicon/         Icons and web app manifest
pipeline/               Scripts and source data that produce assets/data and assets/map
docs/                   Screenshots used in this README
```

The genre and place for a day are chosen from the day of the year, so the pick changes at local midnight and repeats each year.

### Data

The genre and place lists were collected from [Every Noise at Once](https://everynoise.com) and a public dump of Spotify-generated playlists. That original collection and cleaning work lives in `pipeline/notebooks/Orfeu_For_Publish.ipynb`, and its outputs are in `pipeline/source/`.

`pipeline/` turns those lists into the files the site reads:

- `build-genres.mjs` finds a Wikipedia article for every genre and checks each Spotify playlist. It does not take the first page with a matching name: it skips disambiguation pages ("Carnatic may refer to …"), articles about something other than music (a magazine, a band, a record label), and redirects to unrelated pages. Genres with no good match show a short note and a Wikipedia search link instead. A handful of reviewed exceptions live in `pipeline/wiki-overrides.json`.
- `build-locations.mjs` drops rows that are not places (the holiday playlists, "Everything") and playlists Spotify no longer serves. It geocodes each place with OpenStreetMap Nominatim, keeps a result only when it falls in the country the playlist names, and draws `assets/map/world.svg` from Natural Earth country shapes. Geocoding results are cached in `pipeline/geocode-cache.json` so rebuilds don't repeat requests.

Each run writes a report to `pipeline/reports/` that lists the Wikipedia match for every genre and every skipped row.

## Run it locally

```sh
python3 -m http.server 8000
# open http://localhost:8000/
```

## Refresh the data

Requires Node 18 or later.

```sh
cd pipeline
npm install
npm run build        # or: npm run genres / npm run locations
```

Review `pipeline/reports/` and the diff in `assets/data/` before committing. Pushing to `main` publishes the site.
